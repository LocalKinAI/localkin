This is a meta-skill with a decision tree ("Text as banner → pyfiglet if installed else asciified API; Wrap message → cowsay; Decorative border → boxes; Specific thing → ascii.co.uk; ..."). The core value is the routing logic that picks the right tool based on user intent, with fallback chains. That requires LLM round-trips to interpret the request and select among 9 heterogeneous commands. A single exec wrapper cannot capture this — it would reduce to one tool, losing the routing intelligence that makes the skill useful.
